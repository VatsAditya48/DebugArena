
# DebugArena

AI-Powered Proctored Technical Assessment Platform.

## Project Overview

DebugArena is a technical assessment platform where recruiters evaluate candidates through real-world debugging challenges.

## Technology Stack

- Frontend: React, TypeScript, Tailwind CSS, Vite
- Backend: Python, FastAPI
- Database: PostgreSQL, SQLAlchemy, Alembic
- Code Execution: Docker-based isolated runner
